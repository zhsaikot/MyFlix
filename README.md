# 🎬 MyFlix - Netflix-Style Streaming Web Application

A sleek, responsive, and interactive movie and series streaming portal built with **pure HTML5, CSS3, and modern Vanilla JavaScript**, connected to **The Movie Database (TMDb) API** with multi-server full video streaming and official YouTube trailers.

Designed to look and feel like **Netflix**, optimized to run directly on **GitHub Pages** with zero build tools or external dependencies needed!

---

## ✨ Features

- **Full Movie & TV Series Streaming**:
  - Watch complete feature films and TV episodes right in your browser!
  - **Multi-Server Switcher**: Switch seamlessly between Server 1 (Full HD), Server 2 (Fast Stream), Server 3 (VIP 4K), Server 4 (Multi Stream), or Official YouTube Trailer.
  - **TV Episode Selector**: Choose specific seasons & episodes (e.g. S1 E1, S1 E2) to play the full episode directly.
- **Official YouTube Trailers**:
  - Instant trailer preview button on Hero Billboard, Detail Modal, and Player Server Switcher.
- **Powered by TMDb Live API**:
  - Trending Now, Top 10 Movies Today, Popular TV Series, Blockbusters, Critically Acclaimed, Action & Adventure, Sci-Fi & Fantasy, and Comedy Hits.
  - Real actor cast lists, director names, high-resolution original backdrops, match percentage, and similar title recommendations.
- **Live Search & Exploration Grid**:
  - Real-time instant search across thousands of movies and series on TMDb.
- **Top 10 Today Row**:
  - Stylized custom SVG rank numbers (1 to 10) flanking vertical posters, matching Netflix's top 10 charts.
- **Persistent "My List" Watchlist**:
  - Bookmark your favorite titles with one click (persisted in `localStorage`).
